Advanced
========

Processing workflows of the HABLAB experiment: validation of the processing
with calibrated polystyrene beads against Mie theory, batch processing of all
samples into Level-2 files, and post-processing of the Level-2 data with the
inherent optical properties measured on the same samples.

.. note::

   These notebooks rely on data stored locally; they are rendered with their
   saved outputs and are not executed when building the documentation.
